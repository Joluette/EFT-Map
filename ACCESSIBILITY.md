# Accessibility

EFT Position aims to be usable by players with different experience levels and access needs. Accessibility feedback is welcome in **English or Polish**.

## Available controls

- The interface can be switched between Polish and English.
- Themes, accent color, marker size, map opacity and window transparency can be adjusted.
- Quest and extract badges use different shapes as well as colors. Names are available when hovering over markers on the main map; the README includes an [icon legend](README.md#icon-legend).
- Keyboard shortcuts include **Ctrl+,** for settings, **Ctrl+F** for filters, **F8** for the minimap, **F11 / Esc** for the full-screen map, and **F10** to restore full window visibility.
- Minimap settings provide buttons and controls when a global shortcut is unavailable.

The supported environment is Windows x64 with .NET Framework 4.8.

## Known limits

The map artwork is visual. Complete screen-reader navigation of the map, all keyboard-only workflows, and every high-DPI or high-contrast configuration have not been verified. Marker hover labels and drag/resize interactions can be barriers. This document is not a claim of compliance with an accessibility standard.

## Report a barrier

Open a [bug report](https://github.com/Joluette/EFT-Map/issues/new?template=bug_report.yml) and start the title with **Accessibility**. Describe what you were trying to do, what prevented it, and your Windows version and display scaling. Include assistive software and its version if relevant, and a suggested alternative interaction if you have one. Do not include sensitive personal information.
