# Security policy

## Supported versions

Security fixes are considered for the **latest published release** and current source on the default branch. Older releases may require an upgrade; separate fixes are not promised for every historical version. See [releases](https://github.com/Joluette/EFT-Map/releases).

## Report a suspected vulnerability

Please keep vulnerability details, working exploits, credentials, and unredacted logs out of public issues and pull requests.

1. Open the repository's [Security tab](https://github.com/Joluette/EFT-Map/security).
2. If **Report a vulnerability** is available, use it to submit a private report to the maintainer.
3. If that option is unavailable, open a minimal issue titled **Private security contact request**. Say only that you need a private reporting route; do not include the vulnerability, exploit, affected private files, or personal details. Wait until a private contact method is agreed before sharing the report.

In the private report, include the affected version, expected impact, reproduction steps using safe sample data, and any suggested fix. The maintainer will assess the report and may ask for more information. There is no guaranteed response time or paid bounty.

Ordinary map, interface, screenshot-parsing and shortcut bugs can use the [public bug form](https://github.com/Joluette/EFT-Map/issues/new?template=bug_report.yml). Problems in Escape from Tarkov or an unrelated service should be reported to its owner.
