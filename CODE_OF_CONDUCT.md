# Code of conduct

EFT Position is a small community project, made with newer Tarkov players in mind. Questions, bug reports and contributions are welcome, whatever your experience level.

## Working together

- Be respectful and patient. Help people learn without gatekeeping.
- Give specific, constructive feedback about the work.
- Assume good intent, listen to corrections, and keep discussions relevant.
- Respect other people's privacy and the rights of map and asset authors.

Harassment, discrimination, threats, personal attacks, deliberate disruption, spam, and sharing someone else's private information are not acceptable.

These rules apply to the project's issues, pull requests and other project spaces on GitHub.

## Reporting and moderation

For abusive content, use GitHub's **Report content** or **Report abuse** tools. Reporting directly to repository maintainers is available where GitHub offers that option. See [GitHub's reporting guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

For ordinary project moderation concerns, you can open a brief issue linking to relevant public project content. If a private conversation is needed, request a private contact method without posting personal information or private messages.

The project maintainer, [@Joluette](https://github.com/Joluette), may ask for changes, remove inappropriate content, close disruptive threads, or restrict participation. The response should reflect the severity and context of the behavior.
